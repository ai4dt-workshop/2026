# AI for Digital Twins — BNAIC/BeNeLearn 2026

Static landing page for the workshop *"Artificial Intelligence for Digital Twins: Challenges and
Best Practices"* at BNAIC/BeNeLearn 2026, Maastricht University.

Plain HTML/CSS, no build step. Served via GitHub Pages from the repository root (`index.html`).

To preview locally:

```
python -m http.server 8000
```

then open http://localhost:8000.
